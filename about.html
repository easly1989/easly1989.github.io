What I do

I design and build software end to end — from the database and API up to the interface, on the web and on mobile. I like shipping things that are whole: an app you can actually run, own and rely on, rather than a proof of concept. Some of what I build is open source; some is a product I license or host.

The projects on this site are a good picture of that: an open-source finance manager, a group activity planner for phones and the web, a nutrition planner, and a matchmaking-agency system.

How I build

Go backends
Small, fast, dependency-light services in Go — clean architecture and a clear REST API, easy to reason about and to operate.
Embedded SQLite
Pure-Go SQLite means no separate database server to run or back up — the data is a single file you control.
One-container deploys
Each product ships as a single Docker container, often distroless, so it's simple to self-host and cheap to run.
The right front end
Server-rendered HTMX, a React SPA, or Flutter for web, Android and iOS — whichever fits the product best.
Privacy by default
Self-hostable, no unnecessary tracking, and GDPR tooling where personal data is involved. Your data stays yours.
Shipped and maintained
CI, tagged releases, backups and health checks — the unglamorous parts that make software something you can depend on.

How I build

Go backends
Small, dependency-light services in Go, with a clear REST API and a layout that is simple to operate.
Embedded SQLite
Pure-Go SQLite means no separate database server to run or back up — the data is a single file you control.
One-container deploys
Each product ships as a single Docker container, often distroless, so it is cheap to run and straightforward to self-host.
The right front end
Server-rendered HTMX, a React SPA, or Flutter for web, Android and iOS — whichever fits the product best.
Privacy by default
Self-hostable, no unnecessary tracking, and GDPR tooling where personal data is involved. Your data stays yours.
Shipped and maintained
CI, tagged releases, backups and health checks — the unglamorous parts that decide whether something keeps working.

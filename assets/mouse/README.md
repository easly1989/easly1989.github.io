# The mouse on the desk

`mouse.glb` is the computer's mouse in the room (`room-mouse.js`): "Mouse" by CreativeTrio, from
[Poly Pizza](https://poly.pizza/m/V2Ebx3pvo4), under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/), which asks for no credit; it is
credited anyway, here. It is the file as published; the room recolours it to match the computer. The
three.js room (#160) does not use it: its mouse (`gl/computer.js`) is made of a smooth surface, since this model has too few faces
(300 points) to look round up close.

coordinator-monitor

One pane for every local Claude Code session: what each one is doing, its subagents, and everything that waits for you, answerable in place.

What it is

A Claude Code mod

It is a Claude Code mod, built on the early-access function-hooks plugin API. I made it for a coordinator workflow, where you talk to one session and it delegates to many, but it is useful as soon as you run more than one session at a time.

Everything stays on your machine: plain JSON files, no server, no network.

What it shows

One pane, every local session
  • Every session that runs the mod, under its sidebar name, with state, model, effort, context and subagents. Waiting ones come first.
  • With savvy-flow and savvy-progress installed, workers show their tier crab, model, effort and the steps they report. Without them, any subagent is listed.
  • The 5-hour and weekly limits, as the latest session reported them.

What waits for you

Answerable in place
  • Protected commands. Merges, pushes to main, deploys and service restarts that match the rules never run without your approval, whatever the session's permission mode. Approve once, for the session, or deny.
  • The app's permission prompts. While the coordinator's pane is open, they come to the pane too. With no answer in nine minutes, or no pane open, the app's own dialog asks.
  • Questions. A multiple-choice question is forwarded with every option and a free answer field. A turn that ends with a ## Questions for you heading shows its questions with a reply box.

A request leaves the pane as soon as you answer it, and the session receives your answer as a new message.

Install

Claude Code 2.1.316 or later

Mods are early access and the API may change between releases. Clone the repository and add its folder to CLAUDE_CODE_PLUGIN_DIRS in ~/.claude/settings.json, appending if it already holds other folders. 

git clone https://github.com/easly1989/coordinator-monitor.git ~/coordinator-monitor
{
  "env": {
    "CLAUDE_CODE_PLUGIN_DIRS": "~/coordinator-monitor"
  }
}

For a single session, use claude --plugin-dir ~/coordinator-monitor.

The mod has to run in every session you want to see: that is what publishes the session's status.

Use

One command, a few settings
  • /agents-monitor opens the pane in the current session.
  • Set Coordinator folder to the folder name of your coordinator session and the pane opens there by itself.
  • Click a subagent of the current session to open its transcript. Other sessions open from the sidebar.

The README has the other options: language, forwarding questions, the shared folder and your own protected commands.

How it works

Files in a shared folder

Each session publishes its status to a shared folder every three seconds, and the pane reads them all. Your answers are files the pane writes there, picked up by the session on its next tick. A session that stops publishing for 15 minutes drops out of the pane; a closed one stays an hour, marked as ended.

The protected-command rules are a guard against doing something you wanted to supervise, not a sandbox. Keep your normal permission settings.

What it supports

Donations go towards building and releasing more software, and towards releasing more of it openly. Open source is the part of this work I enjoy most, and support is what makes it easier to keep choosing.

The time to build things properly
Getting something finished, and then keeping it maintained, takes rather more evenings than a first release suggests. Support is what keeps that going.
More of it in the open
There are projects I would like to work on publicly, and nothing that is closed today is closed forever — opening more of it up later is something I would like to do.
Somewhere to run it
Hosting for the apps I run for people and for the demos, so anyone can try something without installing it first.

Which one?

What I do

By day I'm a Full Stack Software Developer at TeamSystem. Either way the work is the same shape: the database, the API, and the interface on top of it, for the web and for phones. I like finishing things — an app someone can actually run and keep running, rather than a proof of concept.

The projects on this site are the ones I keep going on my own time. Some are open source, some are licensed, and some I host.

How I build

  • Go backendsSmall, dependency-light services in Go, with a clear REST API and a layout that is simple to operate.
  • Embedded SQLitePure-Go SQLite means no separate database server to run or back up — the data is a single file you control.
  • One-container deploysEach product ships as a single Docker container, often distroless, so it is cheap to run and straightforward to self-host.
  • The right front endServer-rendered HTMX, a React SPA, or Flutter for web, Android and iOS — whichever fits the product best.
  • Privacy by defaultSelf-hostable, no unnecessary tracking, and GDPR tooling where personal data is involved. Your data stays yours.
  • Shipped and maintainedCI, tagged releases, backups and health checks — the unglamorous parts that decide whether something keeps working.

Cupid

A web management system for matchmaking and dating agencies — a cloud-ready rewrite of the classic Cuore desktop application.

Email me about Cupid

What it is

Cupid is a web management system for matchmaking and dating agencies: client records, partner requests, affinity matching, meetings, contracts, printing, GDPR tooling and encrypted backups.

At a glance

Backend
Go 1.25 (chi router), SQLite (modernc.org/sqlite, pure-Go), goose migrations
Frontend
React 19 + Vite + TypeScript + Mantine, i18n (Italian by default)
API
OpenAPI 3 contract with generated server (Go) and client (TS) types
Security
Ed25519-signed license keys (offline verification), CSP + HSTS, login rate limiting, argon2id
Delivery
A single distroless Docker image with the SPA embedded and a /data volume
Licence
Closed source

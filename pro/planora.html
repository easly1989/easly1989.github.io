Planora

Plan together, decide less, do more — a mobile-first shared activity planner that turns group indecision into events worth remembering.

Email me about Planora

What it is

Planora is a mobile-first shared activity planner for groups: a shared backlog of ideas, a guided Organize wizard with date voting, events, reminders and feedback. Web, Android and iOS.

At a glance

Backend
Go + Fiber, Clean Architecture, REST API under /api/v1
Database
SQLite (pure-Go modernc.org/sqlite), WAL, foreign keys, auto-migrations
Frontend
Flutter, Material Design 3, light/dark, responsive — one codebase for Web (PWA), Android and iOS
Auth
Email + password (Argon2id), JWT access + refresh; optional Google / Apple
Delivery
A single multi-arch container (amd64/arm64); the apps point at one backend
